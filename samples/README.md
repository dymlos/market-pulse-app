# Samples

Esta carpeta contiene ejemplos de archivos de entrada para pruebas locales y para guiar futuros imports.

Subcarpetas previstas:

- `csv/` para muestras de importacion

Archivos incluidos:

- `csv/metric-snapshots.sample.csv`: ejemplo valido con headers frecuentes.
- `csv/metric-snapshots-alternative-headers.sample.csv`: ejemplo valido con separador `;` y headers alternativos.
- `csv/metric-snapshots-invalid.sample.csv`: ejemplo con filas invalidas para revisar mensajes de validacion.

Estos archivos son solo ejemplos y no representan datos productivos reales.
